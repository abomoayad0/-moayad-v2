# فحص ٣٩ · صناديقُ النماذج · موانعُ الإلغاء · حارسُ ملاحظة المسحوب · سجلُّ الصادر — ما رجع من القاعدة الحقيقيّة

جرى مرّةً واحدةً في ٨/١٠/٢٠٢٦ داخل `begin … rollback`، بهويّة الموجّه وطالبٍ بحسابه ومفرح (وكيلًا) وبندر (وليَّ أمر). **النتيجة:** ١١ خطوةً رجعت كما صُمّمت، وواحدةٌ لم تُجرَّب لفقد بيانها (١٠).

| # | النتيجة |
|---|---|
| ١ | الموجّه: `v2_my_form_inbox` ⇐ «صندوقُك» · ١٩ · غيرُ مقروءة ١٩ · كلُّها «إليك سرًّا — الموجّه الطلابيّ» وسرّيّة · مسحوبةٌ ١ · أوّلُها نموذجُ الإحالة بحقوله السبعة · و`note_ar` «ما وُصف بالسرّيّة لا يُعرض لغير من وُجّه إليه — ولا يُنقل عنه» ✅ |
| ٢ | الموجّه يُعلّم أوّلَها مقروءًا ⇐ `ok` · `marked` ١ ✅ |
| ٣ | الموجّه يُعلّم صفَّ طالب ⇐ رُفض: «هذا الصفُّ ليس في صندوقك» ✅ |
| ٤ | الطالبُ بحسابه: «صندوقُ الطالب» · ٦ نماذجِ تعويض · مسحوبٌ ١ بعنوان «(مسحوب) … — والسببُ: …» ✅ |
| ٥ | الطالبُ يُعلّم صفَّ الموجّه ⇐ رُفض ✅ |
| ٦ | الوكيل: صندوقُه ٠ — فلا يرى ما وُجّه إلى الموجّه ✅ |
| ٧ | `v2_void_blockers` لأولى بعدها اثنتان ⇐ `can_void` false · موانع ٢ بمعرّفاتها وتاريخها وحالها (الثالثة ثمّ الثانية) · `why_ar` · `confirm_word` «أُلغي» ✅ |
| ٨ | `v2_void_blockers` لآخرها ⇐ `can_void` true · لا موانع ✅ |
| ٩ | `v2_open_records` ⇐ ٢٦ · تنتظر لجنةً ٧ · `waiting_outgoing` ٣ · و`why_ar` يجمع السببين ✅ |
| ١٠ | ملاحظةٌ على نموذجٍ مسحوب ⇐ **لم يُجرَّب**: لا نموذجَ مسحوبًا في صندوق بندر |
| ١١ | صندوقُ بندر: ٠ نماذج (فلا مسحوبَ فيه) |

## ما ظهر (فُحص خارج الفحص بقراءة)

- **من ٢٦ صفًّا موجّهًا إلى الطلّاب: صاحبا أكثرها (٨ و٧) بلا حساب** (`user_id` فارغ · `portal_active` false) — فصندوقُ الطالب يعمل، ولا يفتحه إلّا من له حساب.
