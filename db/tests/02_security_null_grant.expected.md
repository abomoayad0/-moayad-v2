## السبب
الجسور التالية تحرس بـ `v2.my_grant() not in ('owner','admin')` دون `assert_role`، و`my_grant()` ترجع null لمن لا حسابَ له:

- `v2_errors` · `v2_error_fixed` · `v2_outbox_pull`
- `v2_opp_open` · `v2_opp_plan` · `v2_opp_close`
- `v2_entry_grade` · `v2_entry_verdict` · `v2_entry_delegate`
- ومعها الدالّة الداخليّة `v2.caller_kind`

أخطرها `v2_outbox_pull`: يُرجع رقمَ الجوّال ونصَّ الرسالة، ويعلّم الرسائل «sent» فلا تصل إلى أصحابها.
أمّا `v2_errors` فيكشف سجلّ الأخطاء.
