# فحص ٣١ · حدُّ التأخّر — ما رجع من القاعدة الحقيقيّة

## الإصدار ٢ (هذا): ١١ من ١١ · والأوقاتُ عربيّةٌ بلا ثوانٍ

أُعيد مرّةً بعد أن أضافت القاعدةُ `v2.time_ar` والحقولَ `_ar`. وأُبدل السطرُ ٥ ليقرأ `why` وحدَه.

- **١:** `v2_day_rules` ⇐ `assembly_ar` «٠٦:٤٥» · `close_ar` «٠٨:١٠» · `late_cutoff_ar` «٠٩:١٥» · `grace_ar` «٠» · `prenotice_ar` «١٠» · `period_minutes_ar` «٤٥»، والحصصُ بـ`starts_ar` و`ends_ar`.
- **٢–٤:** `at_ar` «٠٦:٤٠» و«٠٧:٣٠» و«٠٩:٣٠». و`why` بعد الحدّ: «وصل بعد حدّ التأخّر (٠٩:١٥) — فيُسجَّل غائبًا لا متأخّرًا».
- **٥:** ١٤:١٢ ⇐ السببُ نفسُه.
- **٦–٧:** الحفظُ ٠٧:٣٠ ⇐ `late` · ٤٥.
- **٨:** حفظُ ١٤:١٢ ⇐ **رُفض:** «وصل الساعةَ ١٤:١٢ وحدُّ التأخّر في مدرستك ٠٩:١٥ — فيُسجَّل غائبًا لا متأخّرًا · نهايةُ الحصّة الثالثة …».
- **٩–١١:** كالإصدار ١.
- **🟡 في بيانات الطفيل:** الإقفالُ ٠٨:١٠ قبل حدّ التأخّر ٠٩:١٥، فالشاشةُ تنبّه في رأس باب الوصول: «الإقفالُ ٠٨:١٠ وحدُّ التأخّر ٠٩:١٥ — راجع توقيتاتك».

---

## الإصدار ١

جرى مرّةً واحدةً في ٦/١٠/٢٠٢٦ داخل `begin … rollback` على الطفيل. وفُحص فيه الطريقُ كما تسلكه الشاشة، لا الدالّةُ وحدَها: قواعدُ اليوم ⇐ التحقّقُ قبل الحفظ ⇐ الحفظ ⇐ وبدلُه تسجيلُ الغياب.

**النتيجة:** ١١ من ١١ كما يُنتظر.

| # | النتيجة |
|---|---|
| ١ | `v2_day_rules`: الاصطفاف 06:45 · المهلة ٠ · الحصّةُ الأولى 07:00 · ٤٥ دقيقة · الإشعار بعد ١٠ · الإقفال 08:10 · حدُّ التأخّر 09:15 «نهايةُ الحصّة الثالثة — افتراضٌ حتى تضبطه المدرسة» · ٧ حصص |
| ٢ | ٠٦:٤٠ ⇐ `present` · «وصل في وقته» · `can_record_arrival` false |
| ٣ | ٠٧:٣٠ ⇐ `late` · ٤٥ دقيقة · «وصل بعد الاصطفاف بـ٤٥ دقيقة» · `can_record_arrival` true |
| ٤ | ٠٩:٣٠ ⇐ `absent` · «وصل بعد حدّ التأخّر (09:15:00) — فيُسجَّل غائبًا لا متأخّرًا» |
| ٥ | ١٤:١٢ ⇐ `absent` · ٤٤٧ دقيقة · السببُ نفسُه |
| ٦–٧ | حفظُ وصولٍ ٠٧:٣٠ ⇐ نفذ ⇐ `late` · ٤٥ ✓ |
| ٨ | حفظُ وصولٍ ١٤:١٢ ⇐ **رُفض:** «وصل الساعةَ 14:12:00 وحدُّ التأخّر في مدرستك 09:15:00 — فيُسجَّل غائبًا لا متأخّرًا · نهايةُ الحصّة الثالثة …» ✓ |
| ٩–١٠ | وبدلُه الغيابُ بالاصطفاف (`not_arrived`) ⇐ `absent` · «لم يصل» ✓ |
| ١١ | تحقّقٌ لمدرسةٍ ليست له ⇐ **رُفض:** «ليست مدرستك» |

## ملاحظة عرض (أُصلحت في الإصدار ٢)

الأوقاتُ في `why` وفي رفض الحفظ تأتي بثوانيها: «09:15:00» و«14:12:00». والشاشةُ تعرض النصَّ كما رجع، فتظهر «٠٩:١٥:٠٠». فإن أردتَها «٠٩:١٥» فمكانُها القاعدة: `to_char(…, 'HH24:MI')`.
