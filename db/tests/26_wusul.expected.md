# فحص ٢٦ · الوصولُ والاصطفافُ والانصراف — ما رجع من القاعدة الحقيقيّة

جرى مرّةً واحدةً في ٦/١٠/٢٠٢٦ داخل `begin … rollback`، بهويّة مفرح وكيلًا لشؤون الطلاب في الطفيل.

**النتيجة:** ١٣ من ١٣ كما يُنتظر، ومعها ملاحظتان على القاعدة.

| # | النتيجة |
|---|---|
| ١ | `can`: record_assembly · record_arrival · record_dismissal كلُّها true |
| ٢ | اليوم دراسيّ · ١٤٤٨/٤/٢٥ · مقيّدون ٤٩ · لم يُرصد ٤٤ · غيرُ مقفَل |
| ٣ | ٣ فصول، ولا فصلَ مكتمل |
| ٤ | حالةُ اصطفافٍ غيرُ معروفة ⇐ **رُفض:** «حالة اصطفاف غير معروفة: x» |
| ٥–٧ | a حاضر ⇐ `present/attended/حضر الاصطفاف` · b غائب ⇐ `absent/not_arrived/لم يصل` |
| ٨ | وصولٌ بلا وقت ⇐ **رُفض**، لكن برسالة قيدٍ إنجليزيّة: «null value in column "arrived_at" … violates not-null constraint» |
| ٩–١٠ | وصولُ b ‏٠٧:٤٠ ⇐ `late` · متأخّرٌ ٥٥ دقيقة · إذنُ موافقة `enter_class` |
| ١١ | انصرافٌ بلا وقت ⇐ **رُفض** برسالة قيدٍ إنجليزيّة: «null value in column "minutes_after" …» |
| ١٢ | انصرافُ a ‏١٣:٤٠ ⇐ ٧٠ دقيقة · «تجاوز 30 دقيقة» · «يُتخذ الإجراء المناسب … ض06» |
| ١٣ | انصرافاتُ اليوم: ١، بدقائقه وعتبته وإجرائه، و«رصده: الوكيل لشؤون الطلاب» |

## ⚠️ للقاعدة

`v2_record_arrival` و`v2_record_dismissal` لا يحرسان الوقتَ الفارغ برسالةٍ عربيّة، فيصل رفضُ القيد بالإنجليزيّة. والواجهةُ لا ترسل النداء بلا وقت، وتكتب «وقتُ الوصول مطلوب» أو «وقتُ الخروج مطلوب».
