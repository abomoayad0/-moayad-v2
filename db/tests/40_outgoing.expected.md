# فحص ٤٠ · بريدُ الصادر — ما رجع من القاعدة الحقيقيّة

جرى مرّةً واحدةً في ٨/١٠/٢٠٢٦ داخل `begin … rollback` على الطفيل، بهويّة مفرح وحساب المدير. **النتيجة:** ٢١ خطوةً رجعت؛ ١٩ كما صُمّمت، واثنتان (٦ و٢٠) **لم تفحصا حارسَ الصفة** لأنّ حسابَ مفرح «مالك» (`owner`) و`assert_role` يُجيز المالكَ قبل كلّ صفة — فلا يُستدلّ بهما على صفة «وكيل شؤون الطلاب».

| # | النتيجة |
|---|---|
| ١ | `v2_outgoing_pending`: ٤ بنودٍ من السلّم تنتظر خطابًا · أوّلُها `edu_decision` و`need_ar` «يُحمل على خطابٍ صادرٍ ولا يُقفل إلّا بجواب إدارة التعليم» · و`note_ar` ✅ |
| ٢ | بلا موضوع ⇐ «موضوعُ الخطاب لا يُترك فارغًا» ✅ |
| ٣ | ينتظر جوابًا بلا موعد ⇐ «… فلا بدَّ من موعدٍ يُراجَع عليه» ✅ |
| ٤ | إنشاءُ خطابٍ يحمل بندين ⇐ «بلا رقمٍ — لم يُوقَّع بعد» · مسوّدة · بندان: `edu_decision` «لا يُقفل إلّا بجواب الجهة» و`edu_report` «يُقفل بخروج الخطاب» · و`note_ar` «أُنشئت المسوّدةُ بلا رقمِ صادر …» ✅ |
| ٥ | خطابٌ سرّيّ ⇐ مسوّدة ✅ |
| ٦ | توقيعُ مفرح ⇐ **نفذ** وأُعطي رقم ٢ — لأنّه مالك (انظر أعلاه)، لا لأنّ الوكيلَ يوقّع |
| ٧ | ما ينتظر بعده: بندان · مسوّدة · مُوقَّعٌ لم يخرج ✅ |
| ٨ | توقيعُ المدير ثانيةً ⇐ «لا يُوقَّع إلّا ما كان مسوّدةً — وحالُ هذا: signed» ✅ (ونصُّ الحال فيه بالإنجليزيّة) |
| ٩ | إخراجٌ بلا قناة ⇐ رُفض ✅ |
| ١٠ | «نظام رسمي» بلا مرجع ⇐ «… فلا بدَّ من مرجع إحالته — وبه يُتابَع» ✅ |
| ١١ | الإخراج ⇐ «خرجت وتنتظر جوابَ الجهة» · `edu_report` done و`edu_decision` open · `note_ar` يقول ما أُقفل وما بقي ✅ |
| ١٢ | إلغاءُ ما خرج ⇐ «… ويُستدرك بخطابٍ صادرٍ بعده يُحيل إلى رقمه» ✅ |
| ١٣ | إقفالٌ قبل الجواب ⇐ رُفض ✅ |
| ١٤ | جوابٌ بلا مرجعٍ ولا خلاصة ⇐ رُفض ✅ |
| ١٥ | الجواب ⇐ «وصل جوابُ الجهة» · أُقفل `edu_decision` ✅ |
| ١٦ | الإقفال ⇐ «مُقفلة · ويبقى في السجلّ لا يُحذف» ✅ |
| ١٧ | إلغاءٌ بلا سبب ⇐ رُفض ✅ |
| ١٨ | إلغاءُ السرّيّ ⇐ «ملغاةٌ — والسببُ: كُتب خطأً» ✅ |
| ١٩ | السجلّ: السرّيُّ «خطابٌ سري — لا يُعرض عنوانُه هنا» · و`status` بالإنجليزيّة بلا `state_ar` ⚠️ |
| ٢٠ | مفرح يفتح السرّيّ ⇐ **نفذ** — لأنّه مالك؛ ولم يُفحص رفضُه لغير المدير والوكيل |
| ٢١ | إرفاقٌ على المُقفل ⇐ «لا يُرفَق على خطابٍ مُقفل شيءٌ» ✅ |
