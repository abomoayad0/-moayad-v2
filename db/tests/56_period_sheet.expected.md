# فحص ٥٦ · لوحة ٤ (كشفُ حضور الحصّة) والإصلاحاتُ النصّيّة — النتيجةُ كما رجعت (مرّةً واحدة)

بحساب المعلّم الحقيقيّ والموجّه — داخل begin…rollback. ولم يُنادَ `v2_session_attendance` (كاتبٌ يُقفل الحضور).

| # | الخطوة | النتيجة |
|---|---|---|
| ① | `v2_period_states` | ✅ أربعةُ أحوالٍ تُختار · و«دخل بإذن» لا يُختار |
| ② | `v2_session_open` | ✅ «فُتحت الحصّة الأولى — بعد ٦٣ دقيقة» · و`at_ar` في الجلسة |
| ③ | `v2_session_sheet` | ✅ «كشفُ حضور الحصّة الأولى … ١٥ طالبًا · 🟠 و١٥ لم يُرصد» · `tally_ar` · `confirmed_ar` |
| ④ | رصدُ `late` بتاريخ الكشف (`on`) | ✅ «متأخّرٌ ٧ دقائق» · والعدُّ «متأخّرٌ واحد» |
| ⑤ | رصدٌ باللفظ «غائب» | ⚠️ رُفض — ونصُّ الرفض يقول «والمقبول: حاضر أو غائب…» وهو يقبل المفاتيحَ لا الألفاظ: **نصٌّ مُضلِّل** |
| ⑥ | رصدٌ بلا تاريخ | ⚠️ رُفض «اليوم <NULL> ليس يوم دراسة» — لا يأخذ اليومَ إن فرغ، ونصُّه فيه `<NULL>` |
| ⑦ | `v2_student_timeline` | ✅ `on_ar` «الثلاثاء ٢٥ ربيع الآخر ١٤٤٨هـ (٦ أكتوبر ٢٠٢٦م)» |
| ⑧ | `v2_grade_plan_open` · `kind_ar` | ❌ لم يُرَ: خطأُ تصميمٍ في الفحص (السطرُ داخل الكتلة التي سقطت فمُحي) — فلم يثبت |
| ⑨ | ردُّ نافذة التعديل | ✅ «…من الفترة (انتهى الخميس ١٤ ربيع الأوّل ١٤٤٨هـ (٢٧ أغسطس ٢٠٢٦م))» |
| ⑩ | الموجّه · `v2_record_period` في حصّة المعلّم | ⚠️ **قُبل** — يُرفع للسؤال: أمقصودٌ أن يرصد الموجّهُ حضورَ حصّةٍ ليست له؟ |
